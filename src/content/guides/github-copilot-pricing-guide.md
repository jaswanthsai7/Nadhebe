# GitHub Copilot Pricing Guide: Free, Individual, Business, and Enterprise Plans (2026)

**GitHub Copilot** pioneered the AI-assisted software development revolution. As GitHub and Microsoft expanded its underlying infrastructure, Copilot evolved from a single autocomplete model into a multi-model ecosystem integrated across VS Code, JetBrains IDEs, and GitHub.com.

With options ranging from a zero-cost **Copilot Free** tier to full **Copilot Enterprise** deployment, this guide breaks down pricing, feature differences, and security guarantees.

## 2. Core Feature Breakdown by Plan

### Copilot Free
- **Completions**: 2,000 ghost-text completions per month.
- **Chat Messages**: 50 prompt exchanges per month in editor sidebars.
- **Requirements**: Free GitHub account; zero payment method needed.

### Copilot Individual ($10/month)
- **Unlimited Completions & Chat**: No monthly request caps.
- **Model Switching**: Toggle seamlessly between **Claude 3.7 Sonnet**, **GPT-4o**, and **Gemini 2.0 Flash**.
- **GitHub CLI Integration**: Natural language bash suggestions directly in the terminal via `gh copilot suggest`.

### Copilot Business ($19/seat/month)
- **Zero Data Retention**: Telemetry and private code snippets are explicitly excluded from model training data.
- **Intellectual Property Indemnity**: Microsoft legally indemnifies customers against copyright infringement claims on generated output.
- **Centralized Seat Provisioning**: Manage licenses and policy controls from the GitHub organization dashboard.

### Copilot Enterprise ($39/seat/month)
- **Deep Codebase Indexing**: Indexes your organization's entire internal code repositories for organization-aware answers.
- **Automated Pull Request Reviews**: Generates contextual pull request summaries, test coverage gap analysis, and changelogs.
- **Internal Knowledge Base Search**: Searches internal markdown documentation alongside source code.
