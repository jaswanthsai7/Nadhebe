# Agent Discovery & DNS-AID Configuration Guide

**Domain:** `nadhebe.com`  
**Standards:** RFC 8288 (Link Headers), RFC 9460 (SVCB/HTTPS), DNS-AID (`draft-mozleywilliams-dnsop-dnsaid`)

---

## 1. RFC 8288 Link Response Headers (Configured in Code)

The following HTTP `Link` response headers have been configured in `public/_headers` to be served by Cloudflare Pages on all responses:

```text
Link: </llms.txt>; rel="describedby"; type="text/plain", </llms-full.txt>; rel="describedby"; type="text/plain", </sitemap-index.xml>; rel="sitemap"; type="application/xml", </api/v1>; rel="api-catalog"
```

### Rel Relations Exposed:
- **`rel="describedby"`**: Points to LLM summary context (`/llms.txt`) and full site text (`/llms-full.txt`).
- **`rel="sitemap"`**: Points to the XML sitemap index (`/sitemap-index.xml`).
- **`rel="api-catalog"`**: Points to the API catalog endpoint (`/api/v1`).

---

## 2. DNS for AI Discovery (DNS-AID) Record Setup (Cloudflare DNS)

DNS-AID uses DNS ServiceMode records (`SVCB` or `HTTPS` record types) under `_agents.nadhebe.com` to allow AI agents to discover entrypoints via authenticated DNS query.

### Step 1: Add DNS Records in Cloudflare DNS Dashboard

Log into **Cloudflare** → **`nadhebe.com`** → **DNS** → **Records** → **Add Record**:

#### Record 1: Agent Index Entrypoint (`_index._agents.nadhebe.com`)
- **Type:** `HTTPS` (or `SVCB`)
- **Name:** `_index._agents`
- **Priority:** `1`
- **Target:** `nadhebe.com`
- **Value / Parameters:** `alpn="h2,h3" port=443 path="/llms.txt"`

#### Record 2: Agent-to-Agent Endpoint (`_a2a._agents.nadhebe.com`)
- **Type:** `HTTPS` (or `SVCB`)
- **Name:** `_a2a._agents`
- **Priority:** `1`
- **Target:** `nadhebe.com`
- **Value / Parameters:** `alpn="h2,h3" port=443 path="/api/v1"`

---

### Step 2: Enable DNSSEC Signing in Cloudflare

1. In Cloudflare DNS Dashboard for `nadhebe.com`, scroll down to **DNSSEC**.
2. Click **Enable DNSSEC**.
3. (If domain registrar is external) Copy the DS record generated by Cloudflare and paste it into your domain registrar's DNSSEC settings.
